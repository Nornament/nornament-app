{% load static %}{% comment %} The splash between navigations. Included by both shells. Its CSS is inline on purpose: an external stylesheet has not necessarily arrived when the first paint happens, and a preloader that itself flashes unstyled is worse than none. Same reason the palette is literal here rather than reading the app's custom properties. It is a translucent scrim rather than a solid cover, so the page stays legible underneath instead of the screen going black. It fades in only after a beat, so a fast page never flashes it, and a CSS animation retires it after eight seconds whatever JavaScript does — a splash screen that can outlive its own script is a site nobody can use. {% endcomment %}
