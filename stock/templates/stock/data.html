The join key is media_id, and it is inside the filename. Never join a spreadsheet back to media on the URL — original links are signed and expire, so a workbook you exported last month points at nothing. media_id does not expire and is never reused.

Bringing a spreadsheet in

The legacy importer read Gati and generic workbooks in the browser. Here the load runs on the server through manage.py load_legacy, against the restored dump — one transaction, wipe-and-reload, so it is idempotent by construction and a half-finished import cannot leave the catalogue in a state nobody can describe.

Run manage.py parity_check after every load. It compares row counts, the sum of every money column and the min/max of every timestamp, table by table, and exits non-zero on any mismatch. See docs/RUNBOOK.md.
